# 机器人适配器契约

## 目的

适配器将厂商设备、ROS 2 Topic/Action/Service 或模拟器映射到稳定的系统契约。新增设备时实现适配器，不改 Agent 工具语义和任务回环核心。

机器人型号、适配器及设备映射由独立的机器人 profile 选择，字段和校验规则见[机器人兼容配置](02a-robot-profiles.md)。配置只组合已实现、已安装的驱动和适配器。

## 插件职责

一个机器人适配器可组合两个接口：

- 感知端：订阅或采集设备数据，转换为标准观测事件。
- 动作端：公布支持的技能，接收经过校验的命令并报告执行生命周期。

设备插件应实现初始化、连接、能力发现、健康检查、关闭和错误报告。掉线、重连和传感器校准状态需可观测。

## 统一观测事件

每条观测至少包含：

| 字段 | 说明 |
|---|---|
| event_id | 全局唯一事件 ID |
| robot_id / device_id | 事件对应的机器人和设备 |
| event_type | 标准化类型，例如 speech.transcript、person.presence、gesture.command |
| observed_at | 设备采集时间；如果时钟不可靠，标明时间质量 |
| received_at | Gateway 收到时间 |
| payload | 类型化内容，含单位、坐标系和必要的置信度 |
| source | 传感器/模型/控制器来源及版本 |
| ttl_ms | 事件可用于决策的有效时间 |
| privacy_class | 数据敏感级别，控制是否可上传或持久化 |

适配器可以额外提供人类可读摘要供 Agent 使用，但摘要不能取代结构化 payload。图像和音频按需引用短时、安全的资源句柄，不把大块二进制塞进状态对象。

交互事件应区分“检测信号”和“用户命令”，至少支持以下语义类别：

- gesture.candidate：候选手势及类别、置信度，不直接执行动作。
- person.presence：画面中检测到人，不代表身份已验证或用户希望交互。
- attention.candidate：视觉模型估计某人正在关注机器人/摄像头；这是可选且带置信度的交互信号，不作为认证凭据。
- wake.detected：唤醒词或已配置触发器满足条件，带触发来源和有效期。
- speech.transcript：有限采集窗口内的语音转写，带时间戳、语言和识别置信度。
- interaction.cancelled：用户或本地策略取消当前交互窗口。

适配器保留原始设备时间与接收时间。触发检测不把未经语音/确认的手势直接伪装成 Agent 可执行命令。唤醒阈值、采集时长和冷却时间来自受版本管理的策略配置。

## 技能能力清单

动作适配器上报带版本的技能描述。每个技能包含名称、参数 schema、单位、参数上下限、前置条件、是否可中断、超时和安全级别。示例技能仅说明接口形状：

~~~json
{
  "name": "head.look",
  "version": "1",
  "parameters": {
    "yaw_deg": {"type": "number", "min": -45, "max": 45},
    "pitch_deg": {"type": "number", "min": -20, "max": 25}
  },
  "interruptible": true,
  "timeout_ms": 3000,
  "safety_class": "low"
}
~~~

示例范围不是任何具体机器人的安全建议；实际限值必须由机器人厂商和本地安全配置确定。

## 动作生命周期

动作命令必须含 command_id、task_id、robot_id、skill、parameters、deadline 和取消策略。回报统一生命周期：

- accepted：命令通过本地校验，已排入执行。
- running：技能已开始，后续可有进度或状态反馈。
- succeeded：控制器反馈与完成条件支持技能完成。
- failed：技能未完成，附机器可读错误类别和可读摘要。
- cancelled：收到取消且执行器确认停止或已进入明确取消状态。

收到 accepted 不能表示动作完成。非幂等动作需用 command_id 去重；是否允许重试由技能策略声明。

## 安全与错误处理

适配器在动作落到驱动前进行参数、单位、坐标系、机器人状态和本地安全规则校验。安全拒绝应返回明确错误码。控制链路中断时，机器人本地按技能策略停车、保持或进入安全姿态，不等待云端决策。

适配器不得自行扩大 Agent 请求的权限、速度、范围或持续时间。低层控制命令和安全覆写接口只能由受信任的本地控制器调用。

## 适配器验证

- 契约测试：能力清单、事件 schema、命令生命周期、单位和错误码。
- 仿真/录制回放：相同输入产生可预测的状态转移。
- 故障测试：设备拔除、超时、重复命令、过期事件、非法参数和取消。
- 实机检查：在安全区域验证限速、急停与断连行为。
