# 安全、隐私与验证

## 安全控制边界

- 本地控制器负责碰撞/避障、速度及活动范围约束、急停、watchdog 和断连策略。
- 云端 Agent 只能提出白名单技能及受限参数；所有动作在本地重新校验。
- 运行时区分安全停止与任务取消，停止反馈需来自执行器而非只清除软件状态。
- 有风险或不可逆动作可配置用户确认；MVP 默认只开放低风险且可中断技能。
- 任务 deadline 到期、状态不确定或传感器失效时，遵循技能的本地 fail-safe 策略。

## 隐私和记忆

- 在机器人端优先做音视频筛选/特征提取，只上传云端推理所必需的最小内容。
- 默认不长期保存原始音视频、脸部图像或可还原的生物特征模板。
- 人脸识别和“主人”身份绑定需有明确同意、访问控制、删除路径和用途限制。
- 看向摄像头只能作为可选注意力候选，不能视作身份验证、动作授权或同意被主动问候。
- 常开触发检测应有清晰的摄像头/麦克风状态提示；优先本地检测/短时缓冲，语音窗口结束后及时丢弃不必要的原始音频。
- 记忆分开保存会话上下文、用户偏好和任务记录，保留来源、更新时间、置信度与过期策略。
- 为模型请求记录数据类别和 provider，不将密钥、私密图像或不必要个人资料写入常规日志。
- 提供按用户/机器人删除记忆和任务数据的能力；保留期限待部署地区与产品需求确认。
- profile 的安全限制只能保持或收紧适配器和本地安全监督的硬限制，不能通过配置放宽硬件能力或安全边界；连接凭证从密钥存储读取，不写入普通 profile。

## 测试层次

### 单元与契约测试

- 事件和工具 schema 校验、单位/坐标转换、技能边界和错误映射。
- 适配器生命周期、能力发现、事件过期和状态合并。
- 命令幂等、状态机合法转移、超时与取消。

### 仿真与回放测试

- 固定感知输入和机器人反馈下的确定性状态转移。
- 延迟/乱序/重复/缺失事件，以及设备断连和重连。
- 动作途中收到急停、障碍事件、用户取消或云端断连。
- 模型输出越权工具、错误参数、重复调用和无效 JSON。

### 端到端验收场景

1. 用户要求机器人抬头；Agent 选择技能；控制器反馈完成；评估确认达到目标。
2. 用户请求移动，但技能超出范围；请求被本地拒绝且机器人不动作。
3. 主人出现事件过期或置信度不足；Agent 不将其当作当前确定状态。
4. 动作运行中触发急停；本地停止不等待云端响应；任务状态更新为取消/安全中止。
5. 云端 API 超时或失联；系统报告任务未完成，物理动作按本地策略停止或安全保持。
6. 动作反馈为失败；事务流读取状态后有限恢复或明确终止，不盲目重复非幂等动作。
7. 切换到不支持 head.look 的 profile 后，该工具不提供给 Agent；手工构造该命令也会被本地拒绝。
8. profile 声明的协议/型号与设备握手结果不一致时拒绝启用动作，不静默使用其他型号的映射或限值。
9. 挥手但未接续语音、注意力误检、低置信转写、多人同时说话和语音窗口超时均不触发运动技能。
10. Agent 提出的唤醒策略修改未经验证/授权不生效；新 profile 在影子测试指标退化时回滚到已知良好版本。
11. 电量低、机器人故障、正在执行用户任务、超出允许区域或环境风险升高时不启动探索；运行中条件失效立即由本地策略中止。
12. 用户正在交互、设置免打扰、刚收到问候、识别到潜在碰撞风险或传感器不可靠时不主动问候/探索。
13. 地图更新候选不得移除禁区或扩大授权区域；未获用户授权的人员不得自动加入朋友/熟人目录。
14. 低电量时按余量转入返航/充电、请求用户协助或 savepower；充电/低功耗状态必须由设备反馈确认。
15. 未列入低风险插件 allowlist 的代码或权限变更即使测试通过也不得自动部署；安全、身份、隐私和密钥规则不可自改。

## 运行指标

至少采集：

- 感知事件到达延迟、过期/丢弃率和适配器健康状态。
- Agent API 延迟、错误率、token/调用成本和每任务模型轮次。
- 工具验证拒绝率、动作开始/完成延迟、技能成功/失败率。
- 急停触发至确认停止时间、断连恢复时间和状态不确定任务数。
- 任务完成率、错误完成率、用户取消率及评估证据缺失率。
- 唤醒精确率/召回率、误唤醒和漏唤醒率、平均交互建立时间及影子策略对照结果。
- 主动行为资格拒绝原因、主动问候频率、探索中止原因和安全边界触发次数。
- 电量阈值切换、返航/对接成功率、求助次数、savepower 进入/退出和相关能耗。
- 插件分类、自动部署门禁结果、canary 健康度及自动回滚次数。
- Supervisor 启动失败检测、回滚时长、恢复模式进入原因、重复崩溃隔离和 LLM 修复提案通过率。

先建立所选机器人上的基线，再设定目标阈值。所有测量按 robot_id、device_id、skill、provider 和任务类型切分，避免平均值掩盖特定设备问题。
