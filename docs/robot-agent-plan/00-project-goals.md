# 项目目标与范围

## 项目目标

构建一个可扩展的机器人交互 Agent：多种感知设备经适配器转换为统一观测；云端 Agent 理解用户目标并选择受限的机器人技能；本地控制器执行动作并保持实时安全；事务回环将真实执行反馈与后续观测融合，评估目标是否达成。

交互不只从文本框开始。机器人应能把经配置的手势、唤醒词或可选视觉注意力信号解释为“准备接收交互”，再通过麦克风采集语音、形成带来源与置信度的任务输入交给云端 Agent。检测到手势或有人注视摄像头本身不等于已经获得一条动作指令。

系统应允许新增传感器或机器人适配器，而无需让 Agent 直接理解新的硬件协议。

面向常见机器人建立经过验证的兼容型号集合。对于已支持的适配器协议族，切换机器人型号应优先通过 profile 配置完成；首次接入新的厂商协议或动作语义时，仍需增加适配器实现。

每个运行时实例只连接并控制一台物理机器人，可管理该机器人上的多个传感器和执行设备。项目支持在不同部署实例上选择不同机器人型号，不负责多机器人同时编排或协同。

## MVP 成功标准

- 用户可以通过文本或语音提交一个简单任务，任务经云端模型规划后调用一个已注册技能。
- 至少一个唤醒路径可端到端工作：明确唤醒词或手势触发有限时长语音采集，转写后形成 Agent 任务；超时或低置信度时不会触发机器人动作。
- 适配器对每个设备报告身份、能力和健康状态，并将感知结果映射成带来源和时间的结构化事件。
- 技能调用具有参数校验和动作生命周期；命令已接受不能被误认为动作已完成。
- 执行反馈和新的传感器观测能够更新同一任务的状态，并用于成功、失败或继续执行的判断。
- 模型超时、云端断连或动作执行失败时，任务能够安全结束、等待或向用户报告，不会无限重试。
- 可从任务 ID 追踪输入事件、Agent 决策、动作命令、执行反馈和最终评估。
- 在隔离测试中用至少两个兼容 profile 验证型号选择、能力发现和限制加载不要求修改 Agent 或事务流中的型号分支；这不代表单个实例同时控制两台机器人。
- 不运行本地大语言模型；实时控制和安全不依赖云端往返。
- 记忆能影响个性化上下文；修改感知唤醒策略必须走提案、验证、授权、版本化部署和回滚流程。
- 主动行为仅在本地资格条件满足时创建，资格失效后可由本地控制立即暂停或停止。
- 低风险且预授权的插件可在自动化门禁通过后自动部署；新增动作权限、唤醒算法、核心代码及安全/隐私相关变更需人工批准。
- 主框架无法启动时，独立监督器可本地回退到已知良好版本并进入安全恢复模式；云端 LLM 只负责可选诊断和修复提案。

目标数值（如响应时间、成功率和恢复时间）须在选定机器人、网络和模型 API 后通过基线测试设定，避免在硬件未知时承诺没有依据的固定指标。

## MVP 范围

- 一个首发实机型号或模拟器，以及一个用于证明配置切换的第二 profile；第二 profile 可用模拟器或独立测试环境验证，实机验证按安全条件分阶段进行。
- 至少一种人机交互入口。建议先完成唤醒词/手势触发加语音转写；视觉注意力联动作为后续阶段。
- 两到三个低风险技能，例如抬头/转向、低速短距离移动、播报。
- 云端 LLM API 由常驻语言进程 `robotsoul.language_gateway` 调用。文本任务、本地语音最终转写和 Dashboard 通话最终转写都作为自然语言交给这个进程。
- Go 版 PicoClaw 只编写隔离工作区中的插件和补丁。它与语言进程的工具权限分开。
- 本地动作执行、状态反馈、安全限幅和任务评估。
- 基本运行日志、关联 ID、故障和延迟指标。

## 非目标

- 在 MVP 中训练、微调或本地部署 VLA / LLM。
- 让云端模型输出电机 PWM、关节轨迹或高速控制环所需的连续控制量。
- MVP 不交付多个厂商型号的完整适配器集合，也不支持单实例控制多台机器人；先完成一个实机型号，并以隔离测试逐步扩展兼容 profile。
- 默认保存原始视频、音频或人脸模板作为长期记忆。
- 无验证地让机器人自动执行危险、不可逆或超出白名单的动作。
- 让模型直接在线修改生效中的传感器阈值、安全边界或主动探索区域。
- MVP 开始即允许在未知空间进行无边界自主移动。
- 让云端 LLM 成为机器人进入安全恢复模式或回到已知良好版本的必要条件。

## 术语

- 观测：传感器或控制器在某一时刻报告的数据。
- 状态：事务流根据多个观测维护的当前估计，可能包含置信度和有效期。
- 意图：Agent 对目标或下一步的语义判断。
- 命令：经过校验、将交给技能执行器的具体动作请求。
- 反馈：适配器或控制器报告的接受、进度、完成或失败信息。
- 事务：从任务接收到结果评估的一次可追踪处理实例；事务不是数据库事务，不承诺物理动作可回滚。
- VLA：通常指将视觉与语言条件映射为机器人动作表示的模型。使用视觉识别结果加工具调用也有价值，但不等同于端到端 VLA。
