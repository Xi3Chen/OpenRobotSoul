# 主动行为策略

## 定义

主动行为是在没有待处理用户任务时，由本地确定性资格策略创建的低风险任务。当前限定为低频问候和授权区域内的受限环境探索。Agent 可以选择表达方式或在许可范围内制定短程目标，但不能授予自己运行资格、扩大边界或关闭安全监督。

主动行为沿用三大模块：适配器提供电量、健康、人员/障碍观测和已验证技能；事务流检查资格、创建和结束任务；Agent 提供较慢的语义选择；本地控制器保持快速闭环。

## 启动资格

每次主动任务开始前，事务流必须从本地状态检查：

- 电量高于型号 profile 配置的启动阈值，并留有完成任务及返回/安全停止的余量。
- 机器人健康，定位/避障和停止能力可用，相关传感器数据新鲜。
- 没有待处理、执行中或用户刚取消的任务，也没有用户正在交互。
- 探索仅在维护者/用户配置并验证的区域内；当前位置和定位置信度满足策略要求。
- 当前不在静音时段或用户设置的免打扰状态；问候频率和重复对象冷却时间未超限。
- 环境风险、人员距离和通行条件满足本地规则。
- 若主动探索消耗电量，预计剩余电量必须覆盖探索、返航和安全余量；否则转入能量管理而不启动探索。
- 云端失联时只允许运行已验证的本地低风险行为；依赖 Agent 继续规划的探索不得启动或继续扩展。

有任何必需状态未知、过期或相互冲突时，资格按不满足处理。

## 行为限制

### 主动问候

- 只使用已授权的播报技能和内容模板/受限生成。
- 遵守时间段、频率上限、最近交互冷却和用户拒绝偏好。
- 摄像头检测到人不等于识别到主人，也不等于对方希望互动。
- 无法确认合适对象时不使用姓名、关系或私密记忆打招呼。

### 环境探索

- MVP 只允许在预先配置且经现场验证的区域，不进入楼梯、道路、门外、湿滑区、未知区域或其他禁区。
- 由本地策略限制速度、单次时长、距离、目标点和能源预算；Agent 输出只能进一步收紧范围。
- 必须有本地可用的避障/停止能力。依赖云端模型逐帧看图和发运动指令不构成安全探索能力。
- 断连、定位丢失、低电量、碰撞/人员风险、障碍物、传感器故障、急停或用户呼叫时，本地立即暂停/停止并报告结果。
- 每次探索都有 task_id、允许区域、能量/时间预算、完成条件和取消条件；到预算即回到安全位置或进入定义好的安全状态。

### 地图与熟人记忆

- 仅当机器人具备经验证的定位/建图能力时，才允许创建或更新地图；探索产生的是带时间、坐标系、来源和置信度的地图候选版本。
- 地图更新通过定位一致性、障碍变化和安全边界校验后才标记为当前地图；未知变化不能自动移除禁区或扩大可探索区域。
- “朋友/熟人”目录需要用户授权或由用户明确确认添加。检测到人员、面部相似或多次相遇都不能自动创建身份记录。
- 保存最小必要的身份标识、授权状态、最近交互和招呼偏好；提供查看、删除和遗忘机制。无法可靠识别时按陌生人处理，不使用私人称呼。

### 电量与充电

- 能量管理由本地策略持续运行，区分低电量提醒阈值、返航阈值和 savepower 阈值，并考虑当前动作能耗及安全余量。
- 若已知充电点可达、定位可靠且机器人支持自主对接，则优先停止探索并执行受限返航/充电技能。
- 找不到可用充电点、对接失败或无法自主充电时，通过已授权的播报/通知方式请求用户帮助；不为了“找人”进入未知区域或执行不安全移动。
- 达到 savepower 阈值或移动/通信状态不可靠时，停止主动探索和非必要动作，保存必要任务状态，关闭可延后的高耗能功能并进入机器人支持的安全低功耗模式。
- 电源状态、充电状态和模式切换结果须由适配器反馈确认，不能以 Agent 调用成功作为进入充电/savepower 的证据。

## 任务状态与中断

主动任务使用来源标签 proactive.greeting 或 proactive.explore，并进入普通任务状态机。它们低于明确用户任务优先级；用户说话、手势唤醒、取消或急停可抢占主动任务。

停止结果应区分 completed、interrupted_by_user、stopped_by_safety、budget_exhausted 和 failed。策略记录中需包含资格判定结果及停止证据，以便评估是否频繁误启动。

## MVP 推进

1. 先实现纯策略测试和模拟器：各种电量、任务状态、区域和传感器健康组合得到确定的允许/拒绝结论。
2. 实现低频、无移动的问候，并验证静音、冷却、用户打断和频率限制。
3. 加入电量资格、返航预算和 savepower 状态测试；有充电能力时在仿真验证返回与对接反馈。
4. 接入受限区域探索。先仿真和现场确认边界，再以最低风险配置做短时实机测试。
5. 最后才允许 Agent 在资格通过后提出有限候选路线；本地验证器裁剪/拒绝路线。

MVP 不将“自主探索未知空间”作为交付目标。扩展区域需要额外的导航、地图、风险评估和现场安全验证。
