# 插件扩展与代码变更生命周期

## 目标

OpenRobotSoul 可通过插件扩展机器人技能、感知能力和外部设备控制，例如灯具、窗帘或空调。插件由 Agent 通过统一工具契约调用，不绕过事务流直接访问硬件。

自动插件部署依赖阶段 8 的 Supervisor、last-known-good 发布槽和恢复模式。在这些能力尚未验证前，插件只允许离线生成和测试，不自动安装到机器人。

PicoClaw 的编码任务可帮助生成或修改插件代码，但必须运行在独立扩展工作区，且该任务不能调用机器人技能。生成代码不等于受信任代码，也不等于已获准控制设备。自然语言会话与编码任务的分工见 [Agent 选型与 PicoClaw 集成决策](11-agent-tooling-decision.md)。

## 插件接口

每个插件包应声明并固定：

- 插件 ID、版本、作者/来源、代码摘要和兼容的 OpenRobotSoul API 版本。
- 设备/机器人适配器依赖、能力列表及工具 schema。
- 读取/写入的状态、调用的外部端点和网络权限。
- 对物理环境的影响、风险分类、可中断性、超时及失败状态。
- 配置 schema、默认关闭的能力和所需用户授权。
- 单元/契约测试、仿真或 mock 测试、资源限制和回滚版本。

插件只通过宿主提供的 capability API 访问资源。禁止任意 shell、宿主文件系统遍历、未声明网络访问、动态下载依赖和绕过本地安全监督。

## 变更风险等级

风险由确定性策略依据能力、权限和影响面分类，不能由 LLM 自我声明。

| 等级 | 示例 | 发布策略 |
|---|---|---|
| L0：只读/无外部副作用 | 读取机器人电量、地图摘要、设备状态 | 来源可信、权限不扩展且检查通过时可自动部署 |
| L1：低影响且明确预授权 | allowlist 中的普通灯光开关、受限播报插件 | 可自动部署，但须沙箱/契约测试、权限检查、仿真或 mock、签名包、canary 和自动回滚 |
| L2：新增动作/设备权限或语义策略 | 新的机器人动作、家具写控制、改变唤醒算法/阈值、访问新的个人数据 | 生成提案和测试报告，用户/维护者批准后发布 |
| L3：安全关键或高影响 | 移动控制器、急停/避障/速度上限、门锁、灶具、供电、权限/密钥/隐私机制 | Agent 不得自行部署；需要显式人工设计、审查和独立安全验收，部分能力可列为禁止插件 |

家具控制不能按插件名称归为低风险。灯光的只读或普通开关可以经用户预授权进入 L0/L1；门锁、加热器、燃气设备和高功率设备应按 L3 处理。

## 扩展流程

1. Agent 根据用户请求或观察到的能力缺口创建 extension proposal，记录目标、涉及设备、能力、权限、风险理由、测试计划和回滚版本。
2. 运行时验证 proposal 只引用已注册的插件 SDK、能力 ID 和设备授权；未知能力、隐含权限或越界代码要求拒绝。
3. PicoClaw 在隔离工作区或临时分支生成插件，不接触生产凭证、用户记忆或运行时主目录。
4. 构建可重复的插件包并固定依赖、API 版本和内容摘要。
5. 执行静态检查、依赖/许可检查、漏洞扫描、插件沙箱测试、契约测试、仿真/mock 和权限差异检查。
6. L0/L1 仅在变更匹配预授权清单且所有门禁通过时允许自动发布。L2/L3 需人工批准；L3 还需独立安全审核。
7. 以不可变版本签名后安装，先 canary；监督器监测启动、崩溃、权限拒绝、错误率和设备健康。
8. 指标退化、崩溃或异常行为触发自动停用和回滚；保存审计证据，避免重复自动重试同一坏包。

新增机器人硬件协议通常属于适配器扩展；它可以自动生成初稿，但必须经过驱动兼容和实机安全验证，不得因普通插件的 L1 自动策略而直接上线。

## 家具控制示例

一个灯具插件可提供 light.get_state 与 light.set_state。工具调用还需检查用户、设备和时间段授权，并记录设备返回的真实状态。Agent 不获得整个家庭网络的通用控制权。

插件新增 door.unlock 或类似高影响工具时，默认按 L3 拒绝自动部署，即使模型测试通过也不改变等级。新技能必须显式列入能力目录、工具白名单和本地执行策略。

## MVP 验收

- LLM 不能选择自己的风险等级；风险由策略根据实际权限求出。
- 预授权低风险插件经过全部自动门禁后可部署；缺少任一门禁时保持未启用。
- 新动作/设备权限、唤醒策略和核心框架变更进入批准流程。
- 高影响和安全关键能力不会出现在普通插件自动部署路径。
- 运行插件无法读取非授权记忆、凭证或任意主机文件。
- canary 异常会停用插件并恢复已知良好版本；审计记录包含包摘要和触发原因。
